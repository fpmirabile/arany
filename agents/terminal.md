# Terminal editing rules

Load when changing interactive terminal behavior, plain or JSONL output, accessibility, cancellation keys, terminal ownership, presentation dependencies or a Run's user-visible projection. Read [the terminal spec](../docs/specs/terminal.md) before changing those behaviors; it owns modes, channels, keys, layout, limits and acceptance scenarios. This file owns implementation constraints.

For cross-boundary work, also load [CLI](./cli.md), [history](./history.md), [security](./security.md), and [clipboard](./clipboard.md)/[image](./image.md) when their triggers apply. Account/backend changes retain [credentials](./credentials.md), [ChatGPT](./chatgpt.md) and [Provider](./provider.md) admission.

## Ownership and data

- Keep `presentation.rs` pure over committed SessionView/RunView facts and the CLI-owned empty unsaved conversation projection. Zero creation sequence denotes that local projection, never a replayed Session; label it unsaved, expose no temporary ID, and refresh linear title/default metadata independently of canonical sequence. Terminal widgets, keys, width, focus, mouse and drafts belong to `terminal`; Engine imports no terminal libraries or presentation state.
- Keep one RAII terminal owner. Its private input, composer, history, linear and view files separate decoding, editing, lazy indexing, append-only output and drawing from lifecycle ownership. Unix raw decoding lives under `input/raw.rs`; non-Unix keys retain Crossterm.
- Composer owns the sole bounded in-memory catalog, scoped to Provider/account. Seed after successful setup/default publication. The picker owns one cancellable refresh; inline replacement retains admissible staging, and linear numbers remain an immutable snapshot until close. Exact custom declarations retain local loading. Cached metadata and keystrokes grant no credential or Run authority.
- Consume committed sequence and ordered agent facts for progress. Coalescing display snapshots never drops canonical Events. Assignment/wait/state/call/usage attribution must come from durable facts, not UI arrival order.
- Display draft counts as graphemes while retaining byte-based admission and reader synchronization. Encoded image size cannot establish model token usage; follow the [terminal measurement contract](../docs/specs/terminal.md#acceptance-scenarios-and-evidence-owners).
- Keep draft, palette, feedback, viewport and reading anchors presentation-local. [History rules](./history.md) own bounded notices and lazy indexing; no presentation state enters Events or Provider context.
- Derive Provider failure guidance only from the last committed non-review call of a failed AgentRun, ahead of earlier recoverable Tool denials. Optional AI review is not a terminal failure cause after human fallback. Attested filesystem denials cannot supply an approval-expiry cause. Cancelled siblings, successful calls and absent records cannot supply a Provider cause. Never render chain-of-thought, raw prompts, token streams, reasoning items, Tool payloads or upstream error bodies in ordinary conversation. Explicit effect approval may show the complete bounded sanitized immutable action solely for the decision.
- Sanitize untrusted text before terminal-cell measurement. Truncate by grapheme/cell width. Conversation pickers prioritize readable titles and focused date/configuration details; exact-ID revalidation remains mandatory. Other identity selectors retain distinguishing UUID suffixes.

## Input and drafts

- The sole raw reader runs on a named thread with a 32-event bounded channel and backpressure. Complete initial cursor-query setup before starting it; otherwise it can steal the acquisition response. Stop/join it before restoring stdin flags/raw mode. Cleanup must not query input after the reader stops; clear the fullscreen backend directly rather than using Ratatui's cursor-preserving `Terminal::clear`.
- Unix Mio/rustix decoding uses nonblocking stdin, four-KiB reads, at-most-64-byte key sequences, strict UTF-8 and closed keyboard/mouse forms. A lone Escape waits at most the existing poll interval. Ignore repeats/releases and unowned focus/mouse events; generate resize events only for changed geometry.
- EOF/permanent read failure ends ownership; WouldBlock/Interrupted does not. Arany owns bounded Unix input directly and selects unmodified published Crossterm; preserve joined-reader cleanup and the idle/active/acquisition PTY-loss gates. Remaining dependency cursor paths need their own fault evidence. [Source distribution](../README.md#try-the-current-build) verifies locked registry selection after extraction.
- A bracketed-paste payload is bounded, taken once and discarded before the next input if ignored. Its body supplies data rather than key events. Whole-record admission, explicit submission and framing deadlines follow [the paste contract](../docs/specs/terminal.md#paste-and-attachments).
- After deletion, resegment the whole bounded draft: removing separators can merge graphemes or regroup regional indicators. Snap to the first surviving boundary at or after the deletion point. Wrapping projects the caret without changing draft offsets or bytes.
- Linear mode uses its separate canonical reader because Crossterm key events require raw mode. Restore nonblocking flags after the reader joins; otherwise signal-flushed input can strand shutdown. Keep the Unix SIGINT listener and separate its notice from terminal echo.
- Accepted canonical segments arrive as characters before their boundary. Update Composer quietly during busy/catalog states; expose only continuation/rejection feedback. Drain an accepted segment before transferring input to model selection; cancellation discards undelivered suffix before restoring retained bytes. This does not guarantee arbitrary queued typeahead. A linear model selector restores its own zero-byte input count, not the saved chat draft.
- After Enter, panel cleanup, suspension or reacquisition, resynchronize the canonical reader's actual retained byte count. Manual/automatic maintenance borrows the same Composer and explicit busy draw path; see [the busy-draft contract](../docs/specs/terminal.md#draft-editing-and-submission). Do not infer busy behavior from an activity row or notice.
- [Clipboard rules](./clipboard.md) own trusted transport/client/process admission. The terminal owns one worker/result, never the reader or Engine. Cancel/join it on modal entry, find, release or suspension and discard late results. Apply only at a complete canonical segment boundary, then resynchronize bytes.
- Keep rejected linear setup/key input as a correction-only suffix until Backspace consumes it. API-key bytes never reach drawing/notice/Event APIs. Secret and visible workspace fields retain their separate atomic bounds and cleanup.

## Terminal behavior

The [terminal spec](../docs/specs/terminal.md) owns observable behavior. Preserve these lifecycle and security invariants while implementing it:

- Emit control sequences only through terminal ownership. Use the primary screen, no alternate screen/focus reporting/title or clipboard OSC, and transient picker-only mouse. Bracketed paste is a bounded Unix inline exception restored by that same owner.
- Register SIGTSTP, SIGTERM and SIGHUP before raw acquisition. Suspension stops/joins input, clears the owned viewport, restores modes and only then self-SIGSTOPs; reacquisition rechecks TTY eligibility and preserves pinned work. Never stop after restoration fails.
- Keep original signal listeners alive through restored committed output and transfer them into reacquired ownership. Tokio process-wide handlers do not revert when a listener drops.
- Restore raw mode, cursor, wrapping, echo and every enabled mode on all exits, errors, cancellation, partial acquisition, unwind and suspension. Pin the presentation mode before release, which clears the linear owner. A missed/coalesced progress snapshot must still emit the appropriate plain or decorated user preview exactly once. Reopen canonical state read-only after restoration before emitting an answer/receipt. A renderer fault can expose only committed sanitized fallback facts or a typed presentation failure.
- Keep Run cancellation distinct from pre-Run admission interruption and compaction interruption. Grace expiration provides no fabricated terminal receipt or remote-billing-stop claim; replay owns the durable outcome.
- Preserve typed terminal/input/cleanup failures through private callers rather than converting them to recoverable operation feedback. [CLI rules](./cli.md) own classification and command consumption.
- All selectable alternatives use vertical rows. Folder consent Ctrl+C exits without persisting a choice; Escape dismisses without changing authority. Modal entry cancels/discards clipboard ownership.
- Setup warnings must remain complete and readable before acceptance. Resize/resume restarts consent review and safe focus; insufficient geometry rejects before sign-in. A secret stays absent from presentation and canonical state even during cleanup.

## Verification gates

[The spec's acceptance map](../docs/specs/terminal.md#acceptance-scenarios-and-evidence-owners) locates existing frame, parser, Composer, history and product owners. Follow [testing rules](./testing.md) to strengthen the owning corpus instead of duplicating tests.

- TestBackend proves semantic frames and monochrome equivalence; native PTYs prove acquisition, input, signals, transient mouse, suspend/resume and restoration. Keep success and meaningful faults at their actual boundary.
- Exact public bytes belong to `exec` text/JSONL, linear output, final receipts and `show`; raw interactive escape bytes are not public goldens.
- A dead stderr sink cannot prove delivery of a mouse-disable sequence. Restored-output signal tests need bounded writer backpressure; a marker may otherwise be read only after reacquisition.
- Native Orca/VoiceOver, macOS, desktop clipboard/keyring and live Provider/vision checks remain separate from synthetic Linux/frame proof. [Next steps](../NEXT_STEPS.md) owns their unverified claims; [the beta plan](../planning/arany-beta/README.md) retains dated results and remaining fault scope.
- Review changed presentation dependencies and enabled/native/transitive surfaces under [security rules](./security.md). Document-only extraction does not certify new runtime behavior.
