# Explicit clipboard transport

Load with Terminal and Security rules for `src/terminal/clipboard.rs`. The terminal owns the operation/result; the Engine and input reader do not own OS clipboard access.

- Linux uses standard Wayland or local X11, not a desktop product. Select the transport from checked local OS metadata, not user PATH, an external host, an arbitrary command or Provider content. Pin the trusted installed client's canonical absolute path and reject writable/untrusted ancestors.
- Clear the child environment and forward only the selected local display/runtime or validated X authority path. Do not forward account credentials, arbitrary environment, network/proxy settings or the user's home as an implicit configuration source. An unavailable selected transport fails without silent fallback.
- Bound type inspection separately from the selected payload, drain stdout/stderr concurrently, discard raw stderr and retain only fixed diagnostics. Own the process group before any fallible pipe setup; keep its leader waitable until group cleanup, then kill/reap on every exit. Child deadlines/cancellation do not claim preemption of arbitrary OS filesystem syscalls.
- Linux type inspection prefers PNG, applies image admission before returning a typed result and refuses another advertised image format instead of interpreting its text/file fallback. Text still uses its separate whole-draft bound. macOS uses the checked system `osascript` JavaScript/AppKit bridge inside the same supervised subprocess owner. It selects PNG before UTF-8 text, rejects other advertised image types, checks pasteboard generation and bounds the type list and selected payload before emitting a closed typed frame. Ordinary PNG/text admission still validates those untrusted bytes.
- Native macOS fixtures use uniquely named synthetic pasteboards and release them after bounded observation. Never substitute the general pasteboard for a fixture. This service gate proves transport/admission; draft, modal cancellation and replay retain their existing Terminal/image owners.
- Read only after an explicit editable-chat action. One worker/one result, no watch loop, automatic submission, key replay, selector activation or clipboard OSC. Modal entry/release/suspend cancels and discards late results; canonical delivery waits for complete pending-segment ownership before draft resynchronization.
- Test through public terminal/product boundaries with synthetic isolated transports. Namespace-owned fixed client paths exercise ordinary executable admission without a production override; a private passwd home and stalled test bus can hold real credential admission without a user account. Assert the complete readiness marker and previous client leader reaping before the next request; a terminated orphan can remain a zombie until the namespace reaper runs. Native desktop protocol/service interoperability remains separate from this synthetic routing, payload and hostile-process proof. Never read the user's clipboard for diagnosis.
