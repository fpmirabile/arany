# Terminal history

Load for `src/terminal/history.rs` or its callers. Read [the terminal spec](../docs/specs/terminal.md#conversation-progress-and-history) for user-visible history behavior and [terminal editing rules](./terminal.md) for lifecycle constraints; this file owns the private history invariant.

- Derive rows from the caller's already-loaded committed `SessionView`. Never read State, Workspace, credentials, or Providers while indexing, searching, or drawing. A Run objective enters history only after its committed snapshot; an accepted answer enters only after its committed terminal outcome. Typed previews and display checkpoints are separately labeled, never accepted Messages. Tool summaries/details derive from admitted facts; rejected display candidates are withdrawn.
- Supply message kind for every visible row and an explicit heading flag. The view owns role markers and user rails; rendered body text cannot determine the speaker. Keep decoration within existing indentation so indexed row counts and source anchors stay stable. Derive transcript padding and visible history capacity from the same layout rule; screen margins never enter message indexes. Preserve four content rows before adding top spacing so narrow setup guidance stays readable.
- Index message row counts and source-byte positions without retaining a second full transcript. Canonical Tool/commentary/incomplete bodies are reconstructed only for counting or visible rows; only the latest bounded transient preview may own copied text. Materialize only messages intersecting the visible window, sanitize before cell measurement, and keep one message's temporary rows bounded by the existing Event size. The find query is at most 64 UTF-8 bytes; rendered row width is capped at 4,096 cells. An unmatched query remains editable and cannot enter the composer or canonical Events.
- An image Message indexes a bounded virtual user body: original text plus generated image metadata, never encoded pixels. Its source-byte anchor belongs to that deterministic body. Borrow text-only messages; construct the virtual body only while counting or drawing an image turn, without storing another transcript or copying Base64.
- Local feedback has its own source identity and remains ordered after the last indexed committed message when recorded. Retain at most 32 notices of 8 KiB each; oversized text keeps a UTF-8 prefix with a visible ellipsis. Coalesce identical consecutive feedback at the same boundary and drop the oldest notice on overflow while preserving surviving anchors. Rebuilds preserve interleaving with committed turns, and find includes feedback. Session switching clears it; terminal reacquisition preserves it. Feedback never enters Events, Provider context, replay, or `show`.
- At the live tail, follow new committed content. While reading older rows, preserve the source-text anchor through appends and width changes; show a textual new-content cue until the user returns to live. Session switching resets the anchor only after the existing empty-draft rule. Selector return and terminal reacquisition preserve it.
- For the same Session and width, replace only the last Run's index after confirming the prior identity. Preview updates do not rescan settled turns. Session, width and compact/detail changes rebuild the index while preserving source-byte anchors. Classic and fullscreen keep separate reading positions; accepted completion replaces the preview at the same assistant source identity.
- On a rebuild of at least 4 MiB with multiple available CPUs, count independent Runs on at most four scoped threads, join them, then construct the ordered index. Borrow the existing message text rather than copying it; smaller rebuilds and incremental appends stay sequential. Count rows without materializing the transcript, including the exact escaped-cell widths of unsafe graphemes.
- Classic native scrollback is a bounded cold projection of the already-loaded SessionView: on the first draw for a Session, retain the newest contiguous suffix of whole Run units within 16 Runs, 64 KiB of escaped rendered row text including trusted headings/rails/indents, and 4,096 rendered rows. Count every native-visible objective, observed Tool summary and currently available answer/checkpoint before materializing rows; keep live provisional text in its existing viewport. The status cue points to `Ctrl+T` for the full managed History. Omitted Runs remain canonical and searchable/exportable and are not backfilled on redraw; later Runs append normally. The complete 200-line live-answer path remains unchanged.
- Keep input and cancellation authority outside find: Ctrl+C, shutdown signals, suspend, and resize must still reach their established owner. Screen-reader mode never uses this index or cursor rewriting.
