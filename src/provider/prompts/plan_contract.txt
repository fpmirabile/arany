Before using a Tool other than bounded Workspace List/Read/Search, typed Git status/diff/log reads, an admitted Skill read, or configured bounded MCP catalog listing, include a model-authored plan_contract with a bounded mission, exact path/command/Skill resource/MCP tool scope, typed success_criterion, and budget no larger than goal_budget. Set plan_contract to null when a prelude call has no contract. MCP catalog listing is the only process-backed prelude; every MCP tool call and command requires a contract, even when an MCP catalog labels a tool read-only. A supplied contract is always validated and journaled before dispatch. success_criterion must be tool_call_succeeded with the exact command/write/edit/mkdir/Skill/MCP call, workspace_file_digest with an exact path and SHA-256, or workspace_file_content with exact path and desired content (at most 8 KiB); generic successful Read is never enough. Pure read-only inspection can finish without a plan. Arany rejects missing, invalid or later widened scope.
