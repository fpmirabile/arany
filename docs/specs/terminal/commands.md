# Terminal: interactive commands

## Interactive commands and completion

The [compiled registry](../../../crates/arany-cli/src/terminal/commands.rs) owns command names, aliases, arguments and availability; Workspace, Provider, Skill or stored text cannot add or redefine commands. Only an exact lowercase name after a slash at column zero is a command; `//text` submits `/text`. Unknown commands get local suggestions and never reach the Provider. No-argument commands accept trailing whitespace and reject extra arguments. Selected children use the [agent-chat input](./selectors.md#agent-chats).

Typing `/` at the end of the draft opens a completion list below the input with at most 20 rows. A bare `/` shows Commands and Skills tabs (Left/Right switches; the active tab is inverted, bold and bracketed), or one list under the saved Combined preference. Once text follows `/`, one filtered list shows built-in commands, then admitted Skills alphabetically, each Skill row marked `(skill)`. Up/Down focuses, Tab fills the name, Enter invokes it (`/resum` then Enter opens the resume picker) and Escape closes without editing. Outside the menu, Tab completes a unique command name, value or cached model; an ambiguous one leaves the draft unchanged. Placeholders never enter the draft. Completion does no catalog or credential I/O, and offered effort levels are not compatibility evidence.

With native Tools and remembered folder trust, or explicit private Tool configuration, the list includes admitted project and runtime Skills, at most [64 Skill](../limits.md#max_skills) names. Discovery uses only `.agents/skills`. A Skill named like a compiled command is omitted, so a Skill named `help` cannot replace `/help`. `/name [task]` then Enter submits a turn with the Skill attached and the whole draft, slash token included, as the message. Tab completes `/name ` without submitting; listing and completion run no Skill content. Linear input accepts `/name [task]` too. During a Run `/name` is rejected, since it starts a new turn. The [Portable Skills contract](../tools/skills-and-mcp.md#portable-skills) owns attachment, loading and the `skills-lock.json` installer notice; invoking a Skill grants no authority. Broken configuration shows recovery and no Skill candidates. `/permissions` refreshes candidates after a trust change.

A leading `/name` that resolves to a command or admitted Skill shows accent and bold in the composer. Echoed messages highlight only an accepted Skill invocation, so `//help` and `/goal /help` stay plain; committed Skill messages are headed `You (skill):`. These labels show recognition, not execution or authority. Child chat stays literal text.

Idle `/settings` and `/limits` take no arguments and edit the private `ui-preferences.json` (1 KiB<!-- unrelated-bound: UI preferences record cap -->) through numbered `NAME: VALUE` rows in an inline [selector](./selectors.md#selectors), titled `Settings` or `Limits`. `/settings` rows: Slash menu (Tabs or Combined), Chat view (Fullscreen or Classic), Copy on select (on or off), Newline shortcut (Shift+Enter by default, Alt+Enter or Ctrl+Enter), [Guard](../tools/host-commands.md#guard-mode-and-extra-reads) (auto by default, required or off, saved to the account root's `guard.json`), `Guard folders ›` (Enter, or `NUMBER` in linear mode, removes a saved extra read folder) and seventh `Limits ›` (linear `Choice 7: Limits: opens /limits`). Closing `/limits` returns to `/settings` with its edits kept, and saving `/settings` saves both. `/limits` rows:

- Provider calls, tokens and active time per task (the Goal budget keys), `unlimited` by default;
- default and maximum command timeout (2 min and 10 min initially);
- Build memory (4.0 GB), [256 processes or threads](../limits.md#max_build_processes_or_threads), 1.0 GB writable project storage, and Build cache size, `unlimited` by default (`0 B` disables), showing current use (`Build cache: unlimited (default) · 3.2 GB used`), as [Tools](../tools/commands-and-cache.md#persistent-workspace-build-cache) defines;
- Build jobs and Build CPU cores, automatic by default or 1 to the machine's core count; CPU cores set a quota on Linux only ([macOS keeps supervised CPU thresholds](../tools/limits-and-failures.md#limits-and-failure-behavior)).
- Context window, `100%` of the model's window by default, a percentage from 10% to 100% (`80%`) or a token count from 32,768 to 2,000,000 (`500k`, `1m`, `500000`); `exec` and `serve` use the same value, and [Session context](../session.md#context-and-compaction) owns how a Run resolves it;
- Editor changes: files and Editor changes: size, the bounds of one [editor integration](../execution/events-and-outcomes.md#worker-journal-protocol): 1 to [`MAX_EDITOR_CHANGE_FILES`](../limits.md#max_editor_change_files) files and whole MiB up to [`MAX_EDITOR_CHANGE_BYTES`](../limits.md#max_editor_change_bytes), defaulting to [`DEFAULT_EDITOR_CHANGE_FILES`](../limits.md#default_editor_change_files) and [`DEFAULT_EDITOR_CHANGE_BYTES`](../limits.md#default_editor_change_bytes), never `unlimited`.

These are policy bounds, not a platform or disk-space guarantee; the [Goal defaults](../goals.md#lifecycle-budgets-and-recovery) keep [`MAX_GOAL_RUNS`](../limits.md#max_goal_runs), with no dollar-spend guarantee. A row at its default shows ` (default)`. Digits 1-9 or Up/Down select a row, Left/Right cycle its values, Backspace or Delete restores the default and Enter saves; Escape or Ctrl+C closes without changes. Rows that take typed values open an inline field on Enter with an accepted-input hint; an invalid value keeps the field with a notice. Context window presets cycle `100%`, `75%`, `50%`, `1m`, `500k`, `256k`, `128k`, skipping presets above the model's window.

Linear mode prints `Choice N: NAME: VALUE` rows with an input hint each (newline values `shift+enter`, `alt+enter`, `ctrl+enter`) and accepts `NUMBER VALUE` lines, like `/model`; `NUMBER default` restores the default. Durations need `s`, `m`/`min` or `h` (`30s`, `5m`, `0.5h`, `1 min 30s`); sizes need `B`, `KB`, `MB`, `GB` or `TB` (`512MB`, `8GB`), case-insensitive, resolving exactly to whole milliseconds or bytes; displayed values use the [human-readable formats](./entry-and-modes.md#human-readable-measures) and re-enter exactly. Budgets take a number, duration or `unlimited`; Build cache also takes `unlimited`; Build cores and jobs take `automatic` or a count; Context window a percentage or a count with optional `k` or `m`. Bare numbers for durations or sizes and out-of-range values are rejected. Empty Enter saves and `q` cancels; anything else invalid reports `Type NUMBER VALUE from the list; q cancels`. Under `--classic`, the chat-view hint says the saved view applies to sessions without the flag.

Execution budgets are copied into each new Goal before any work, constrain that Goal, are reused on resume and never widen Tool grants. The record stores only changed keys, so other rows follow the running binary's defaults, and it is [tolerant](../execution/persistence.md#incompatible-records): unknown keys, malformed JSON and invalid values fall back to defaults and are never rewritten by reading. Unsafe or oversized files show recovery without being overwritten. A failed or busy save keeps the current values, reports failure and never claims rollback of an uncertain write. A new newline shortcut applies only after a confirmed save; failed, busy or [Uncertain](../execution/events-and-outcomes.md#effect-outcomes) saves keep the old one without retrying. The [fixed newline bindings](./drafts-and-paste.md#draft-editing-and-submission) always remain. The shortcut row shows the fallback, how to set up manual mappings and the modifier-loss warning. Settings and limits are locked during admission, Runs and compaction.

Inline `/help` opens a scrollable numbered [selector](./selectors.md#selectors) of every command; Enter or Escape closes it. It works during Runs. Linear help prints the full list. Help marks optional arguments, including the current-conversation `/fork` form, and does no State, credential, catalog or Provider I/O.

`/clear` aliases `/new` and deletes no history. `/compact` creates derived context. `/model` owns model and effort; `/effort` and `/models` are unknown, and `/models` suggests `/model`.

`/permissions` offers Folder trust, Typed Git rules, Host command rules, Command environment, Command tools, Network domains and [Git hooks](../tools/git.md#git-hooks) while idle and only inspects during a Run; changes apply from the next Run. Remembered consent never supplies missing native Tool protection. The [Tool contract](../tools/trust-and-approvals.md#folder-trust-and-approvals) owns trust, approval modes, AI review and Guard limits.

- **Typed Git rules** list saved verb, decision and folder or user-wide scope, and add, change or remove rules from fixed choices. The `git push` and `gh pr create` rows say they are unavailable. [Tools](../tools/git.md#typed-prefix-rules) owns typed rules.
- **Network domains** list saved `Network(domain:…)` rules, add one from an unlisted host seen in a command result of this conversation, and change or remove rules; [Tools](../tools/commands-and-cache.md#network-grants-and-egress-proxy) owns their effect.
- **Host command rules** list literal token prefixes with decision, folder and cwd, and change or remove them. Add starts from a recent eligible host command, showing its argv and cwd, then asks for the prefix length and decision. Cancelling before the first save leaves settings absent. On leaving, the editor says whether anything was saved and keeps the latest save failure; an [Uncertain](../execution/events-and-outcomes.md#effect-outcomes) save ends editing with a reopen-to-verify notice. [Tools](../tools/host-commands.md#remembered-host-prefixes) owns exclusions, warnings and mode restrictions.
- **Command environment** lists the record's source, PATH entries and selected names with values hidden until revealed, and adds a non-secret name from Arany's environment or removes one. A missing record is created from the process environment on first open. Capture from login shell and Re-capture need a fresh [host approval](../tools/host-commands.md#primary-host-commands). An unconfirmed creation or save ends the editor with a reopen-to-verify notice, and Tools refuse to start while a creation stays unconfirmed.
- **Command tools** selects a Rewrite hook or Prefix wrapper from granted executables with fixed arguments; Import from Claude Code settings proposes user-level Bash hooks the same way. A selected tool stays disabled until a Guard probe succeeds and a human accepts it; Escape cancels the probe, and an unfinished probe is reported unknown and never retried. [Tools](../tools/hooks.md#hook-execution) owns the rules.

Folder consent fills the chat area: the question, the full folder path (`~` for home; full path in linear mode), a short explanation, the detected runtime profiles and caches or saved pins (each deselectable before Trust), and two vertical choices. Trust and profile controls stay unavailable until every explanation page has been read in order; resize or resume restarts the review. [Tools](../tools/trust-and-approvals.md#folder-trust-and-approvals) owns when consent appears, its choices and outcomes. Escape continues with read-only chat unless explicit `--tools` supplies configuration. A remembered folder is rechecked against its saved identity before use. There is no unsandboxed fallback.

The optional runtime explanation shows the selected Rust environment, offline Cargo prerequisites and Build defaults from the [Tool contract](../tools/commands-and-cache.md#persistent-workspace-build-cache), with the cache-disclosure warning. Command results keep Cargo's own pass/fail/ignore output.

Shift+Tab cycles the [approval modes](../tools/trust-and-approvals.md#folder-trust-and-approvals) without touching the draft or a pending request; the composer names the mode.

A pending effect replaces the composer with a `Tool approval` block showing the operation title, the complete sanitized action, `↓ N more lines · PgDn` while more remains, `Do you want to proceed?` and numbered vertical choices: `1. Yes`, any eligible scoped approvals, and `No` last. No follows the [interruption rules](./entry-and-modes.md#interruption-suspension-and-restoration) and sends no feedback to the model. Guarded approvals open with Yes focused, [primary host commands](../tools/host-commands.md#primary-host-commands) with No focused. Scoped choices:

- Switch to Auto edits for `file edits`, only when Request approvals alone caused the question; it also approves this action once.
- For an eligible primary host request, the [session and host-prefix choices](../tools/host-commands.md#remembered-host-prefixes); the proposed prefix is the model's or the first two arguments, and shells, interpreters and wrappers offer only the exact command. The prefix warning shows the full token list and explains settings creation, Provider disclosure and non-rewindable effects. Auto/acceptEdits offer no session choice; Auto edits then adds `Shift+Tab to Request offers session approval for later eligible commands`.
- A guarded command asking for new [extra read directories](../tools/host-commands.md#guard-mode-and-extra-reads) offers `Yes, and always allow these folders in every trusted folder`, listing each directory with the model's reason.
- In Auto approval, a push to a destination other than the folder's pinned repository offers `Yes, and treat this destination as this folder's repository`, which pins it from the next Run ([same-repository rule](../tools/git.md#human-approved-host-git)).
- A local Git write no rule matched offers the [typed prefix choice](../tools/git.md#typed-prefix-rules) `Yes, and allow git commit in this folder from the next Run` (or `git branch`, `git switch`).

Guarded commands and local MCP calls ask only for extra read directories or under a user ask rule. When the Run has no sandbox, every host approval starts with `sandbox off: commands run on your machine`, and the status line repeats it. Host warnings name host authority, Provider disclosure, non-rewindable effects and that State and the journal are not protected from the same user. A sensitive path puts its warning first, in the warning color or as plain text without color. Host PR-list approval shows the exact repository and filters and warns that private data goes to the current Provider. Superseded project approvals are archived intact with a notice and need fresh approval. Privilege-escalation commands get an exact command to run by hand, never an approval.

Digits select and confirm only while the approval owns input; arrows and Tab move focus and Enter confirms. Yes and remember choices stay unavailable until every page of the action has been shown; an early approving digit shows `Review the whole action first (PgDn)` and records nothing. Enter or PgDn advances, Up/PgUp goes back, and resize or suspension restarts the review. A screen too small for the action allows only denial.

Keys typed before the dialog appears never answer it: it first draws dim without focus (linear: without the `Select` prompt), discards pending input, then draws armed. If that cannot be confirmed within one second, input closes without a verdict. This binds the verdict to the full action, so hostile text or a steering Enter cannot approve an unseen effect. Linear mode prints the action and rows, then `Select 1-N, yes or no; empty Enter denies:`; numbers pick a choice, `yes` is one-use Yes, `no` or empty Enter denies, case-insensitively; anything else is rejected.

Typing `@` after whitespace opens local file and directory suggestions. These are UI reads, not model Tool calls, and create no Events; only the chosen or typed path enters the message.

- Unquoted paths and JSON-quoted paths with spaces work, with or without a trailing slash. Directories end in `/`.
- Typing searches names and relative paths case-insensitively, exact names and prefixes first; an empty query lists the folder's entries.
- Up/Down selects. Tab or Enter inserts a quoted file mention without sending; for a directory Enter inserts it and Tab enters it. Escape keeps the draft.
- Suggestions follow the [typed discovery rules](../tools/file-operations.md#typed-read-discovery): ignored, protected and hidden names never appear, and file contents are never read.
- At most 64 candidates show. Suggestions never block typing; when the index is busy or too large they show busy or unavailable, never an empty folder, and the draft is kept. The index refreshes after 30 seconds<!-- unrelated-bound: mention index lifetime --> and whenever the folder or permissions change.

At Run admission, mentions become [bounded include snapshots](../session.md#context-and-compaction), at most 16 distinct paths and no permission grant; a directory contributes only its listing. Mention failures name the path and say whether a symbolic link, filesystem boundary or non-directory blocked it; an unfinished quoted mention reports `unterminated quoted path`.

## Storage report

`arany storage` reports the Workspace, StateRoot and account-root storage as bounded text on stdout, without a Provider or account; failures go to stderr. A complete report succeeds, including absent roots; a partial or refused one exits unsuccessfully with known subtotals labelled. [Tools](../tools/commands-and-cache.md#local-storage-inventory) owns what is counted, including the [cache recovery contract](../tools/commands-and-cache.md#persistent-workspace-build-cache).

Idle `/storage` shows the same report in a read-only pager (Up/Down, PageUp/PageDown, Home/End; Escape, Enter or Ctrl+C closes) without creating a Run or history; it is locked during a Run. Linear mode prints it to stderr. Escape or Ctrl+C cancels collection. Reports are never journalled, exported or shown to the model; the model may suggest `/storage` but never sees the result.

## Rewind

Idle `/rewind` opens the checkpoint panel; so does Esc Esc within two seconds on an empty composer. On a nonempty draft, Esc Esc saves and clears the draft instead, and Up recalls it. A focused menu takes Escape first, and the first Escape announces the second. Rewind is locked during a Run, admission or compaction, never automatic, and unavailable in `exec`. Attached images or another retained draft must be submitted or cleared before switching conversations.

Rows run in conversation order, newest focused: `Run N · objective excerpt · time · K files changed since` (`file` for one) or `no code changes since`, plus `Before rewind` rows, which offer code restoration only. Excerpts are at most 80 characters; inherited times are labeled. Later autonomous Runs read `Goal run k` under their Goal; steering notes create no checkpoints. Enter offers Restore code and conversation / Restore conversation / Restore code / Never mind; code choices appear only when there is something to restore. Unknown or open publications, or read-only access, disable code actions with the reason; conversation restore stays available.

Code choices open a paged preview: each path's state (restore, delete, recreate, drifted, history drift, unavailable, unsafe, outside grant or kept), `+added -removed` counts (unknown for binary content) and the [non-rewindable effects](../tools/changesets-and-checkpoints.md#checkpoints-and-rewind). Cancel / Compare / Restore are vertical rows with Cancel focused; Restore needs every page read in order, and resize or suspension restarts the review. Compare shows a per-file picker and diff pages (minus for the current file, plus for the checkpoint), each at most 64 KiB<!-- unrelated-bound: escaped rewind diff page -->; binary comparisons say unavailable. Compare grants no file access. If anything changed when confirming, a new preview is needed.

Drift refuses the whole batch and lists the files. Resolve offers Cancel, `Restore the others, keep these files` and `Overwrite changed files (their current content is saved first)`; both need review and Restore on a new preview, and Overwrite first needs its own Cancel / Overwrite confirmation with Cancel focused. An empty plan refuses. [Tools](../tools/changesets-and-checkpoints.md#checkpoints-and-rewind) defines drift and which paths can only be kept.

Receipts state the outcome: `Restored K files to before Run N`, `Rewind refused: M files changed outside Arany`, or `Rewind outcome unknown: inspect files before continuing` when [Uncertain](../execution/events-and-outcomes.md#effect-outcomes). If conversation restore fails or is cancelled after code restore, the receipt reads `Code restored; conversation unchanged; use /rewind → Restore conversation`. Conversation restore switches to a fork ([Session contract](../session.md#conversation-rewind)), or an unsaved conversation for the first prompt, keeps next-Run defaults and puts the selected prompt and images unsent in the composer, a leading slash escaped. Images return as [attachments](./drafts-and-paste.md#paste-and-attachments); an image that cannot be reattached stops the rest with `image restoration failed: REASON`, and unsupported control characters are dropped with a notice. Restored text follows the [draft limit](./entry-and-modes.md#public-limits-and-compatibility). Linear mode prints the restored draft as not sent.

Unavailable checkpoint storage offers Retry / Reset checkpoint storage / Cancel. Reset needs the full warning read and a separate Cancel / Reset confirmation with Cancel focused; healthy, busy, unsafe or concurrently changed storage refuses.

All modes share these states and words. Linear mode lists numbered rows and accepts numbers or full choice names; empty Enter, q, Ctrl+C or EOF cancels; paths, previews and diffs print in full. Narrower panels keep fewer hints (80+ columns all; 50–79 choose, review and cancel; below 50 arrows, Enter/PgDn and Escape). Below 16 columns<!-- unrelated-bound: rewind minimum viewport width --> or eight rows, actions require resizing. Paths, excerpts and diffs are escaped untrusted data.
