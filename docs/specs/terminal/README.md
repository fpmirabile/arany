# Terminal and output contract

## Scope and related contracts

This contract covers attached chat, local controls, presentation, accessibility and deterministic process channels. It does not certify live accounts, every terminal or native platforms; [Next steps](../../../NEXT_STEPS.md) owns open defects and unperformed native, assistive-technology and fault-timing checks.

[Session](../session.md) owns lifecycle and compaction. [Credentials](../credentials.md) own saved-account scope, storage and authorization. [Provider](../provider/README.md) and [ChatGPT](../chatgpt.md) own model, consent and billing admission. [Architecture](../../architecture/system-overview.md#8-terminal-presentation) owns physical responsibilities.
