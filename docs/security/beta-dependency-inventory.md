The macOS-only packages add no Cargo custom-build or `links` declarations, but CoreFoundation/Security framework FFI and native trust/key-store behavior remain required review/evidence. ## License and advisory status

All 300 selected Linux third-party identities declare nonempty license metadata, with 22 distinct raw expressions. The five historical slash-form declarations retain their [pinned MIT-alternative source review](./beta-legacy-slash-license-source-research.md). `option-ext 0.2.0` still declares `MPL-2.0`; native compound expressions and Unicode notices remain separate distribution obligations. The new filter/parser metadata fits the existing reviewed allowlist without broadening it. Metadata is not proof of a chosen license branch, linked-code notices or legal compliance.

`option-ext` enters only through `arany → directories 6.0.0 → dirs-sys 0.5.0 → option-ext 0.2.0` in the current locked graph. The sole application use of `directories` is `StateRoot::default_path`. Its [pinned Linux path](https://docs.rs/directories/6.0.0/src/directories/lin.rs.html) selects an absolute `XDG_STATE_HOME` or the home directory's `.local/state`, then appends `arany`; its [macOS project path](https://docs.rs/directories/6.0.0/directories/struct.ProjectDirs.html) is `Library/Application Support/dev.Arany.arany`. Removing the dependency would eliminate this license branch but must preserve both locations, the home-directory fallback, and rejection when no safe absolute path is available. The standard-library [`home_dir` contract](https://doc.rust-lang.org/std/env/fn.home_dir.html) is a candidate, but [Rust's release notes](https://doc.rust-lang.org/stable/releases.html#version-1900-2025-09-18) place its empty-`HOME` fallback fix after Arany's declared Rust 1.88; a replacement cannot assume exact parity there. Native macOS behavior remains unverified. Keeping the branch is not automatically prohibited by MPL: [Mozilla's official FAQ](https://www.mozilla.org/en-US/MPL/2.0/FAQ/) says an unmodified MPL component in a larger executable requires informing recipients how to obtain that component's source. Arany's current `NOTICE` has no such component-source notice, though the explicitly non-redistributable candidate bundle does. The user approved a version-specific cargo-deny metadata exception on 2026-10-02; it does not complete the release obligation or imply legal clearance.

All 246 selected macOS third-party identities also declare nonempty license metadata, with 21 distinct expressions. The macOS-only packages declare `MIT OR Apache-2.0`; that does not clear Apple-framework behavior or redistribution obligations.

`cargo-audit 0.22.2` and `cargo-deny 0.20.2` remain complementary. On 2026-10-04, `cargo audit -D warnings --db /tmp/arany-effectful-advisories-20261004` fetched 1,290 RustSec advisories, updated the index, scanned all 458 locked packages and exited zero without warnings. `cargo deny --locked --offline check` passed advisories, bans, licenses and sources with nonfatal duplicate-version warnings, without editing [deny.toml](../../deny.toml); that lane uses its cached feed rather than the private fresh audit feed. The version-specific `option-ext` exception remains metadata policy only. Neither result certifies redistributed notices/source bundles, platform behavior or future advisories.
