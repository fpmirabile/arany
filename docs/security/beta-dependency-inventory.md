Both macOS normal-plus-build trees select the same 209 package identities: Arany, 26 direct third-party dependencies, and 182 transitive third-party dependencies. The [toolchain pin](../../rust-toolchain.toml) is Rust 1.98.1; the package's declared minimum is 1.88, matching Ratatui 0.30.2's declared minimum. On 2026-10-01, offline locked metadata showed that 324 of 433 packages declare a `rust-version`, none above 1.88, while 109 omit it. This is only a manifest compatibility screen: this host has no Rust 1.88 toolchain or cached `rust:1.88` container image, so an actual minimum-version build remains unverified.

## Build-time and native authority

In the selected Linux normal-plus-build tree, 32 third-party packages declare a Cargo custom-build target and 24 declare a procedural-macro target. Both are compiler-host code-execution surfaces, not just runtime libraries. Three active packages declare native `links`: `aws-lc-rs 1.18.1`, `aws-lc-sys 0.45.0`, and `libsqlite3-sys 0.38.2`. The [manifest](../../Cargo.toml) enables `rusqlite/bundled`, which normally selects the SQLite amalgamation C source in `libsqlite3-sys`; `reqwest/rustls` selects Rustls → AWS-LC and the native build in `aws-lc-sys`. The [SQLite](./findings/sqlite-build-environment-override.md) and [AWS-LC](./findings/aws-lc-system-autodetection.md) build-environment findings record how ambient state can override these expected native inputs; feature selection alone is not artifact provenance. The [AWS-LC pinned-source note](./beta-aws-lc-build-provenance-research.md) maps its target-specific source and build controls without clearing the artifacts. The selected ICU4X data crates have a distinct [external-Rust-source override](./findings/icu4x-external-data-source.md) under `ICU4X_DATA_DIR`; the current Linux build output does not activate it. Local crate manifests and build files confirm these paths. Filtered metadata includes optional packages absent from the selected normal/build tree; do not treat metadata membership as evidence that they ship in this binary.

Each macOS selection has 29 custom-build packages, 18 procedural-macro packages, and the same three Cargo `links` declarations. The five macOS-only packages have no custom-build target or Cargo `links` field, but `core-foundation-sys` links Apple's `CoreFoundation` framework and `security-framework-sys` links its `Security` framework through `extern "C"` bindings. `security-framework` enters through both `rustls-platform-verifier` and `apple-native-keyring-store`. These FFI, key-store, and platform-trust-store paths add macOS-specific review and native behavior requirements; an offline graph does not validate their runtime behavior.

The [macOS TLS decision](./findings/macos-tls-platform-network-fetch.md) accepts the published verifier and standard OS trust evaluation, which may make auxiliary certificate-related connections. Native macOS TLS behavior and separation of OS certificate traffic from Arany payloads remain unverified.

A native same-user `secret-tool` client retrieved a synthetic Arany record from this host's unlocked collection; the test deleted it afterward without touching the fixed default slot. ## License and advisory status

All 268 Linux-selected third-party packages declare a nonempty Cargo `license` field; they use 20 distinct raw strings. Five selected packages use the historical slash spelling of SPDX `OR`: `fallible-iterator`, `fallible-streaming-iterator`, `ident_case`, `vcpkg`, and `signal-hook`. Their [pinned package-source review](./beta-legacy-slash-license-source-research.md) identifies an MIT alternative and exact packaged text for each; release approval of that choice and a complete notice bundle remain open. `option-ext 0.2.0` declares `MPL-2.0`; `aws-lc-sys` and `aws-lc-rs` declare compound expressions; Unicode-related packages include `Unicode-3.0`. These declarations are **not** proof that the chosen license branch, bundled native notices, or redistributed artifacts meet policy. A complete license/notice assessment must include all release targets and bundled upstream code.

`option-ext` enters only through `arany → directories 6.0.0 → dirs-sys 0.5.0 → option-ext 0.2.0` in the current locked graph. The sole application use of `directories` is `StateRoot::default_path`. Its [pinned Linux path](https://docs.rs/directories/6.0.0/src/directories/lin.rs.html) selects an absolute `XDG_STATE_HOME` or the home directory's `.local/state`, then appends `arany`; its [macOS project path](https://docs.rs/directories/6.0.0/directories/struct.ProjectDirs.html) is `Library/Application Support/dev.Arany.arany`. Removing the dependency would eliminate this license branch but must preserve both locations, the home-directory fallback, and rejection when no safe absolute path is available. The standard-library [`home_dir` contract](https://doc.rust-lang.org/std/env/fn.home_dir.html) is a candidate, but [Rust's release notes](https://doc.rust-lang.org/stable/releases.html#version-1900-2025-09-18) place its empty-`HOME` fallback fix after Arany's declared Rust 1.88; a replacement cannot assume exact parity there. Native macOS behavior remains unverified. Keeping the branch is not automatically prohibited by MPL: [Mozilla's official FAQ](https://www.mozilla.org/en-US/MPL/2.0/FAQ/) says an unmodified MPL component in a larger executable requires informing recipients how to obtain that component's source. Arany's current `NOTICE` has no such component-source notice, though the explicitly non-redistributable candidate bundle does. The user approved a version-specific cargo-deny metadata exception on 2026-10-02; it does not complete the release obligation or imply legal clearance.

All 208 selected macOS third-party packages also declare nonempty license fields, with the same 20 raw strings and the same five slash-form packages. The five macOS-only packages each declare `MIT OR Apache-2.0`; that does not by itself clear Apple-framework or redistributed-notice obligations.

`cargo-audit 0.22.2` and `cargo-deny 0.20.2` are installed. The prior lockfile's offline scan found `paste 1.0.15` unmaintained and `lru 0.12.5` unsound; Ratatui 0.30.2 and Crossterm 0.29.0 remove `paste` and select patched `lru 0.18.5`. On 2026-10-02, `cargo audit -D warnings` with a fresh private `--db` path fetched 1,280 RustSec advisories, updated the crates.io index, scanned all 433 locked packages, and exited zero without warning. The approved [cargo-deny policy](../../deny.toml) scopes the three selected release targets, denies unknown registries and Git sources, and fails on unmaintained and unsound advisories. Its current offline locked check passes advisories, bans, licenses, and sources (with nonfatal duplicate-version warnings) after the user-approved, version-specific `option-ext 0.2.0` `MPL-2.0` exception. This offline deny result uses its local advisory cache; it is not a second scan against the fresh private RustSec feed. A passing license-metadata gate is not legal judgment or redistribution clearance. The [pinned native license/notice source research](./beta-native-license-notice-research.md) identifies relevant AWS-LC and SQLite files but does not clear redistribution obligations. No complete notice audit or cross-platform source/license clearance exists from this inventory. A fresh advisory result is point-in-time evidence, not a guarantee against later advisories or unreviewed source behavior.

3. Extend the selected-entrypoint reviews through transitive build/macro behavior, exact expansions, native source/FFI, enabled features, duplicate versions, and transitive `unsafe` against the locked versions. Include the Linux Secret Service graph and macOS CoreFoundation/Security framework bindings, then verify platform behavior on a native macOS runner. All-target metadata resolution is available offline, but it is not source or artifact review.
4. Build release artifacts through the [guarded entry point](../../scripts/release-build.sh) from the reviewed lockfile and pinned toolchain in a controlled environment, close the [SQLite](./findings/sqlite-build-environment-override.md), [AWS-LC](./findings/aws-lc-system-autodetection.md), [ICU4X](./findings/icu4x-external-data-source.md), [libc fixed-name executable](./findings/libc-build-path-executable.md), and [native compiler-input](./findings/native-compiler-environment-inputs.md) findings on each native target, then verify remaining compiler/PATH/SDK provenance and publish artifact checksums/signatures. Re-run the inventory after every dependency, feature, target, or lockfile change.
5. Build and test the locked graph with Rust 1.88 before claiming support for the declared minimum. The selected-target metadata review does not replace that compiler gate.
