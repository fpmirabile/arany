## `option-ext` release path

Mozilla's [MPL 2.0, sections 3.1-3.4](https://www.mozilla.org/en-US/MPL/2.0/) requires that covered executable code's source form be available, that recipients be told how to obtain it, and that source-form license notices be preserved. Mozilla's [FAQ, questions 8, 11, and 22](https://www.mozilla.org/en-US/MPL/2.0/FAQ/) specifically discusses compiling unchanged MPL code into a larger executable, file-level copyleft, and the placement of source notices. This does not require relicensing Arany's separate source files under MPL, but it does require a release-specific source and notice path for the MPL component.

The candidate bundle includes the exact published [`option-ext 0.2.0` source archive](https://static.crates.io/crates/option-ext/option-ext-0.2.0.crate) beside the binary, checks its locked SHA-256 `04744f49eae99ab78e0d5c0b603ab218f515ea8cfe5a456d7629ad883a3b6e7d`, identifies its MPL-2.0 source and packaged `LICENSE.txt` in the notice, and ships the license text separately for readability. Arany does not modify that source. This addresses the specific source-availability packaging path without resolving all release attributions. Add `MPL-2.0` to the allowed policy only after the complete distribution bundle, all target artifacts, and release-owner license judgment are reviewed; a green metadata check alone cannot certify the binary.

## Patched Crossterm source

Arany now replaces registry `crossterm 0.29.0` with a local [Cargo `[patch.crates-io]` entry](../../Cargo.toml). The [vendored package](../../vendor/crossterm-0.29.0/Cargo.toml) still declares MIT. A file comparison against the locally cached published 0.29.0 package found only one changed source file, [`src/event/source/unix/mio.rs`](../../vendor/crossterm-0.29.0/src/event/source/unix/mio.rs), plus Cargo's `.cargo-ok` cache marker absent from the vendor tree; the [vendored `LICENSE`](../../vendor/crossterm-0.29.0/LICENSE) is byte-identical to the published package's license. This is a scoped source comparison, not provenance or binary-content proof. The published [Crossterm 0.29.0 source listing](https://docs.rs/crate/crossterm/0.29.0/source/) is an independent versioned reference.

That MIT license contains `Copyright (c) 2019 Timon` and requires retaining its copyright and permission notice in copies or substantial portions. The modified source tree already retains the text; the final binary distribution should also carry the complete, unaltered Crossterm MIT notice in accompanying materials. MIT does not itself require publishing the patch or marking modified files, but Arany's source-reproducibility promise now depends on providing the patched tree and clearly distinguishing it from the upstream registry archive. Do not cite the upstream archive checksum as proof of the modified bytes.

[Cargo's package documentation](https://doc.rust-lang.org/cargo/commands/cargo-package.html) says `cargo package` removes `[patch]` from the packaged manifest; Arany's [source-archive script](../../scripts/source-archive.sh) therefore builds a separate archive with the top-level manifest, lockfile, and vendored tree, then checks that Cargo selects the local Crossterm path after extraction. The Linux candidate pairs that verified archive with the binary and carries the complete packaged Crossterm MIT text plus a readable patch/source pointer in its bundle-specific notice. The source-package [Arany `NOTICE`](../../NOTICE) still has no Crossterm entry; the final release owner must decide the permanent notice layout. The candidate does not resolve the other third-party attributions below.
