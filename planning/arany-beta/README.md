## Interface and resource contract

Implement the command grammar, Event schema, lifecycle, provider outcomes, and limits in the canonical architecture and decision register. The Event journal is canonical; views and compaction snapshots are derived. Each Run pins provider/model, Workspace snapshot facts, collaboration policy, and one aggregate budget before `RunStarted`. The fixed beta limits include an 8 KiB user objective, 64 KiB Event payload, 256 MiB SQLite cap with 4 MiB admission headroom, 64 store requests, at most 32 queued updates, at most eight direct children, 4,096 output tokens per call, and 120/300-second call/Run deadlines. Durable limits reject or backpressure visibly; content is never silently truncated. The attached progress observer uses one latest-snapshot slot within that update ceiling and explicitly coalesces superseded display states, never canonical Events.

## Security model

The protected assets are credentials, Workspace input, Session history, canonical Events, and terminal integrity. CLI selections and trusted user configuration establish authority before any Workspace content is read. The Workspace, provider output, replayed text, and custom endpoint responses are attacker-controlled data. Immutable Run settings are the normalized authorization decision; the effective beta capabilities are bounded read-only Workspace input and Arany-issued requests to one selected Provider. Auxiliary OS certificate-related connections are outside that payload authority. Children receive narrower assignment capsules. There is no sandbox or Tool execution claim.

State is private, owner-checked, no-follow, and outside the admitted Workspace. Inputs are handle-relative, no-follow, bounded snapshots. Only the selected Provider credential is loaded. Native origins are compiled; custom endpoints require exact current data-free conformance. Human output neutralizes controls and bidi; JSONL is serialized. Secrets and raw content do not enter diagnostics or telemetry. An unavailable capability, malformed state, missing evidence, limit breach, or cancellation fails closed with a safe typed result. Every dependency, native/build script, procedural macro, and application `unsafe` is reviewed before release.
